02 · What we changed

Four small habits did the work.

Each habit removes waiting or rework, and none needs a new tool.

We made four changes. Requests stay small, so a review fits in one sitting. Each request names its reviewer, so nobody wonders whose turn it is. The first look happens the same day. Comment templates cut rework because authors know what a good request contains. All four are habits, not tools. These are illustrative, and the takeaway on each card says what to remember.
