# Worked example: chest pain as care patterns

26 slides for physicians and underwriters (a clinical validation session, decision-free): 16 main slides, an appendix divider, a stability slide, and one profile card for each of the eight care patterns. It is the deck this skill was extracted from. The live source is `slides/chest-pain/` (edit and rebuild there, output `slides/chest-pain-care-patterns.html`); this folder is a reference copy, so copy `slides.html` and `data.js` back here after a change. It shows:

- `deck.json`: Ethos brand, one injected table.
- `slides.html`: every slide kind (cover, statement with a sentence and with a number, content, dark, divider, closing) and 12 compositions.
- `data.js`: counted, illustrative, draft and concept datasets, placeholders in nested strings, `DECK.checks` that verify the tallies.
- `builders.js`: four deck-specific builders (`seqStrip`, `timeline`, `verdictGrid`, `bundleCard`) and six station pictures for slide 5 (`G.art.guideline`, `cohort`, `bag`, `clusters`, `sequence`, `pubmed`).
- `inject/photo.json`: the PubMed logo (NLM, from pubmed.ncbi.nlm.nih.gov) for the last picture. The live deck also injects the presenter's photo; this copy keeps initials.
- `inject/rows.json`: the eight care patterns with their five events and three sequences each, generated by `gen_rows.py` from `nb/repr_learn_chestpain/outputs/final_table_chestpain_k8_AHA.xlsx`.

Rebuild (writes `build/chest-pain-care-patterns.html` here; the project copy lives in `slides/`):

```bash
python3 -I .claude/skills/html-deck/scripts/assemble.py .claude/skills/html-deck/assets/example-chest-pain
```

Regenerate the rows after a new run (pandas needed):

```bash
/opt/miniconda3/envs/ethos_llm/bin/python -I .claude/skills/html-deck/assets/example-chest-pain/gen_rows.py nb/repr_learn_chestpain/outputs/final_table_chestpain_k8_AHA.xlsx .claude/skills/html-deck/assets/example-chest-pain/inject/rows.json
```

Use it as a reference for patterns, not as a template to edit: start from `assets/starter/` for a new deck.
