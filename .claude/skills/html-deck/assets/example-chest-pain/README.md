# Worked example: chest pain as care patterns

30 slides for physicians and underwriters (a working session on predicates and composites, decision-free): 15 main slides, an appendix divider, and 14 backup slides (stability, validation, guideline coverage, psychiatric timing, identical records, limitations, biases, and one profile card for each of the eight care patterns). It is the deck this skill was extracted from. The live source is `slides/chest-pain/` (edit and rebuild there, output `slides/chest-pain-care-patterns.html`); this folder is a reference copy, so copy `slides.html`, `data.js` and `builders.js` back here after a change. It shows:

- `deck.json`: Ethos brand, injected tables.
- `slides.html`: every slide kind (cover, statement with a sentence and with a number, content, dark, divider, closing), 14 compositions, and the `.room` band (a label plus one line above the footnote: "For the room" with an open question on four slides, "Goal" on the first content slide) on five slides.
- `data.js`: counted, illustrative, draft and concept datasets, placeholders in nested strings, derived rows built from another dataset, `DECK.checks` that verify the tallies and cross-check one dataset against another (the window-fit count against the timing dots).
- `builders.js`: six deck-specific builders (`seqStrip`, `timeline` with `pitch` and `window` options, `verdictGrid`, `bundleCard`, `chipField`, `gapTable`) and six station pictures for slide 4 (`G.art.guideline`, `cohort`, `bag`, `clusters`, `sequence`, `pubmed`).
- `inject/photo.json`: the PubMed logo (NLM, from pubmed.ncbi.nlm.nih.gov) for the last picture. The live deck also injects the presenter's photo; this copy keeps initials.
- `inject/rows.json`: the eight care patterns with their five events and three sequences each, generated by `gen_rows.py` from `nb/repr_learn_chestpain/outputs/final_table_chestpain_k8_AHA.xlsx`.
- `inject/preds.json`: predicate families, reuse counts, window-fit counts and guideline coverage, generated by `gen_preds.py` (standard library only) from `nb/repr_learn_chestpain/outputs/chest_pain_all_patterns.md` and `nb/repr_learn_chestpain/codesets_v2.yaml`, so no predicate count on a slide is typed by hand.

Rebuild (writes `build/chest-pain-care-patterns.html` here; the project copy lives in `slides/`):

```bash
python3 -I .claude/skills/html-deck/scripts/assemble.py .claude/skills/html-deck/assets/example-chest-pain
```

Regenerate the rows after a new run (pandas needed):

```bash
/opt/miniconda3/envs/ethos_llm/bin/python -I .claude/skills/html-deck/assets/example-chest-pain/gen_rows.py nb/repr_learn_chestpain/outputs/final_table_chestpain_k8_AHA.xlsx .claude/skills/html-deck/assets/example-chest-pain/inject/rows.json
```

Regenerate the predicate counts after a new page or code file:

```bash
python3 -I .claude/skills/html-deck/assets/example-chest-pain/gen_preds.py nb/repr_learn_chestpain/outputs/chest_pain_all_patterns.md nb/repr_learn_chestpain/codesets_v2.yaml .claude/skills/html-deck/assets/example-chest-pain/inject/preds.json
```

Use it as a reference for patterns, not as a template to edit: start from `assets/starter/` for a new deck.
